# Changelog

## v1.0.2 — first public release candidate

- Automatic previews inside hierarchical schematic sheets for KiCad 10.0.6 Windows x64.
- Version-specific patcher with validation, original-file backup and restore.
- Optional full-installation-directory backup.
- Local persistence of the last selected KiCad installation directory.
- Context-aware **Cancel** (before an operation) and **Finish** (after a completed operation).
- Separate ZIP distribution rather than a KiCad installer.

Windows functional testing of installation and restoration was reported successful. Publication and independent testing remain separate milestones.
